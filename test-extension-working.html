🚀 How to Use in Scratch

  1. Add Extension: Click the Extensions button in Scratch and select "Teachable Machine"
  2. Load Model: Use the "use model [url]" block with your Teachable Machine URL
  3. Start Detection: Use "start detection" to begin pose recognition
  4. Handle Events: Use "when model detects [label]" hat blocks to respond to detections
  5. Get Information: Use reporter blocks to get predictions and confidence scores
  6. Control Video: Use video control blocks to manage webcam feed

🔍 Troubleshooting

If extension doesn't appear in Scratch:

  • Make sure Scratch GUI is built: npm run build in scratch-gui directory
  • Check browser console for errors
  • Verify extension is registered in extension-manager.js
  • Ensure extension is added to extensions/index.jsx
