Console Functions

You can also use these functions directly in the browser console:

// Check current status MLExtension.getIds() // Set session and project IDs MLExtension.setIds('session_aa3bffbf72c444c5', 'eff8a1b8-4998-442a-a3a2-2e386ddbc9b8') // Fetch project name from API MLExtension.refreshProjectName() // Check if project name needs updating MLExtension.checkProjectNameStatus() // Force UI refresh MLExtension.forceUIRefresh() // Set project name manually MLExtension.setProjectName('My Project') // Test API connection MLExtension.testConnection() // Test CORS configuration MLExtension.testCORS() // Clear all data MLExtension.clearStorage()

How It Works

The extension now automatically:

  • Fetches the project name from /api/guests/session/{session_id}/projects/{project_id}
  • Updates the category name from "sample" to the actual project name
  • Stores the project name in localStorage for persistence
  • Provides functions to manually refresh and manage the project name

Note: The extension name change may require a page refresh or workspace refresh to be visible in the Scratch interface.
