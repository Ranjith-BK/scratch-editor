Extension Integration

This extension will be automatically loaded when Scratch starts and will:

  • Load TensorFlow.js and Teachable Machine libraries
  • Automatically detect teachableLink from URL parameters
  • Load the model and extract labels from metadata
  • Initialize webcam for pose detection
  • Provide real-time predictions
  • Update dropdown menus with actual model labels
